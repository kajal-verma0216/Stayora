
# Stayora 🏡

Stayora is a property listing web application currently under development. It is built to explore and manage property listings for vacation stays and popular travel destinations.

## Features

- View all available property listings
- View individual listing details
- Create new property listings
- Edit existing listings
- Delete property listings
- Dynamic page rendering with EJS templates
- MongoDB database integration using Mongoose

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Templating:** EJS, EJS Mate
- **Other Tools:** Git, GitHub, method-override

## Getting Started

### Prerequisites

- Node.js and npm installed
- MongoDB installed and running locally
- Git installed (optional, for version control)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kajal-verma0216/Stayora.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Stayora
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Ensure your local MongoDB server is running. The current application connects to:

   ```text
   mongodb://127.0.0.1:27017/Stayora
   ```

5. Start the application using the start script defined in `package.json`, or run `node app.js` if no start script is configured.

6. Open your browser at:

   http://localhost:8080
